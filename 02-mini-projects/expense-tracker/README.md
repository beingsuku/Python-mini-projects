# Expense Tracker

A Python command-line application to record, manage, and summarize personal expenses.

## Features

- Add expenses with amount, category, and description.
- View recorded expenses.
- Calculate total spending.
- Generate category-wise expense summaries.
- Save and load expense records using JSON.
- Handle invalid inputs.

## Technologies Used

- Python 3
- JSON
- Dictionaries and Lists
- Functions
- Exception Handling
- `pathlib`

## How to Run

From the repository root, execute:

```bash
python 02-mini-projects/expense-tracker/Expense_tracker.py
```
