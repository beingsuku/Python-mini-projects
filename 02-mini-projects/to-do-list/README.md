# To-Do List App

A simple Python command-line application to manage daily tasks.

## Features

- Add new tasks.
- View all saved tasks.
- Remove tasks by selecting their number.
- Save and load tasks using JSON.
- Handle invalid menu choices and task selections.
- Handle missing JSON files.

## Technologies Used

- Python 3
- JSON
- Lists
- Functions
- Exception Handling
- `pathlib`

## How to Run

From the repository root, execute:

```bash
python 02-mini-projects/to-do-list/to-do-list.py
```
